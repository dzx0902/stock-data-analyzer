# 阶段 4 至阶段 10 功能说明

## 策略提醒

支持价格上下穿、收益率、亏损率、回撤、仓位上下限、买卖区间、
再平衡、波动率和价格变化幅度提醒。

应用启动后，`monitor_strategy_alerts` 后台线程会检查已启用规则。
触发后通过飞书通知并自动关闭该次规则。

示例：

- `如果浮盈超过 10% 提醒我`
- `黄金占总资产超过 20% 提醒我`
- `金价跌到 500 元以下提醒我`

## 分批买入与再平衡

`build_buy_plan` 按权重分配总预算，保证各档金额之和等于预算。
`calculate_rebalance` 根据黄金市值、总资产和目标占比计算应买入或卖出的金额。

## 统一路由与帮助

路由器区分查价、价差、市场、量化、账本、档案、策略、宏观、复盘、
回测、实物黄金和帮助。无法确定意图时返回 `needs_clarification=true`。

发送 `你能做什么`、`怎么用` 或 `帮助菜单` 可直接查看功能，不依赖模型。

## 宏观面板与事件

宏观面板支持美元指数、美债收益率、实际利率、CPI、非农、
美联储预期、人民币汇率、原油、黄金 ETF、央行购金和地缘风险。

每项因子保留数值、变化、来源和时间。事件日历可持久化 CPI、
非农、议息会议等事件，并按时间范围查询。

## 周报、月报与交易复盘

复盘读取真实账本，输出期间交易数、当前持仓、均价、已实现盈亏、
手续费影响，以及频繁交易、追高和连续集中买入等行为提示。

## 策略回测

支持：

- 定投
- 移动平均
- RSI
- 网格
- 买入持有对照

指标包括总收益、年化收益、最大回撤、年化波动、夏普比率、胜率、
交易次数、手续费和相对买入持有的超额收益。

回测输入必须是按时间排序的历史收盘价，不会自动使用未来数据。

## 实物黄金

支持记录名称、克重、纯度、品牌、渠道、购买日期、购买金额、
证书号、发票号、存放位置、图片引用和备注。

估值会按纯度折算足金克重，并同时计算市场估值和回收估值。
删除实物记录必须生成草稿并回复 `确认操作` 后执行。

## 统一 Agent 工具

`extended_gold_assistant` 是阶段四到十的统一工具入口。支持：

- `create_strategy_alert`
- `build_buy_plan`
- `rebalance`
- `macro_panel`
- `macro_events`
- `weekly_review` / `monthly_review`
- `backtest`
- `physical_add` / `physical_list` / `physical_value` / `physical_delete`
- `help` / `classify_intent`
