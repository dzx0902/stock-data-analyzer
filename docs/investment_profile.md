# 用户投资档案与个性化建议

## 档案字段

`investment_profiles` 保存：

- 投资目标：保值、长期配置、短线交易、避险、实物收藏
- 风险等级：低、中、高
- 目标黄金仓位
- 单笔最大买入金额
- 最大回撤容忍度
- 偏好渠道
- 报告风格
- 提醒偏好
- 默认成本法
- 是否允许输出操作倾向建议
- 总资产

比例使用 0 到 1 的 `Decimal`，金额使用十进制定点字符串持久化。

## 自然语言示例

- `记住我的黄金目标仓位是 15%`
- `我的风险偏好比较低，目标是长期配置`
- `以后默认用先进先出计算收益`
- `单笔最多买 5000 元`
- `以后报告写得简洁一点`
- `我只需要信息，不要给操作建议`
- `查看我的黄金投资档案`
- `根据我的持仓给出建议`

明确包含“记住”“以后”“设置我的”等表达时，Agent 会直接解析并更新档案。

## 建议约束

个性化建议会读取档案和黄金账本，结合风险等级、目标仓位、投资目标、
单笔上限及渠道偏好调整表达。用户关闭建议后，只输出事实和风险信息。

所有建议必须包含风险提示，不承诺收益，也不输出绝对化买卖指令。
