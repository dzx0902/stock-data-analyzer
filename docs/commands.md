# 飞书命令示例

## 查价

- `现在国内金价是多少`
- `查一下国际黄金`
- `周大福今天多少钱一克`
- `银行金条和上金所差多少`
- `现在金店金价溢价高吗`
- `把国际金价按 7.2 汇率折算成人民币每克`

价差分析由 `analyze_price_relationships` 工具处理。默认运行时获取实时
USD/CNY 并缓存 5 分钟。可以配置 `USD_CNY_PROVIDER_URL` 接入自定义 JSON
供应商；所有实时供应商失败后才使用 `USD_CNY_FALLBACK_RATE`，且结果会明确
标记 `is_fallback=true`。

如已配置 AllTick，可设置 `ALLTICK_USD_CNY_SYMBOL=USDCNY`。系统会依次尝试
自定义供应商、AllTick、东方财富、Yahoo，最后使用 ECB 最新工作日参考汇率。

## 记账

```text
记账：买入 10 克，单价 500 元，手续费 5 元
```

Agent 只生成草稿。回复：

- `确认记账`：写入数据库
- `取消记账`：取消草稿

撤销最近交易同样需要确认：

```text
撤销上一笔
确认操作
```

## 截图记账

发送包含黄金成交记录的图片。Agent 会识别多笔交易并生成批量草稿，回复 `确认记账` 后原子提交。

## 真实成本和批次

- `查看每一批黄金的剩余克重和盈亏`
- `按先进先出计算当前已实现盈亏`
- `按回收价 550 元卖出 20 克，手续费 10 元，实际到账多少`
- `指定批次 batch-001 卖出 5 克`

支持移动平均、FIFO 和指定批次三种成本法。交易费用可拆分为手续费、点差、
加工费、税费、交付费和仓储费。

## 投资档案

- `记住我的黄金目标仓位是 15%`
- `我的风险偏好比较低，以后默认按先进先出计算`
- `单笔最多买 5000 元`
- `查看我的黄金投资档案`
- `根据我的持仓给出建议`

档案会在进程重启后保留，并用于调整仓位分析、风险重点和报告风格。

## 报告

- `生成近 7 天黄金舆情 Word 报告`
- `用最近 180 天行情生成黄金量化报告`

Word 文件生成前会实际执行质量检查；不合格内容会尝试补充证据或改为材料不足说明。
